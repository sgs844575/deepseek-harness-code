# Release v0.1.2 —— 八期：13 项批修 + 新会话视图改版

发布日期：2026-08-16 · 平台：Windows x64（免安装 zip，解压即用）

## 总览

本版本聚焦两类工作：**13 项 UI / BUG 批修**（欢迎页、附件上传、会话标题、归档闭环、
最近聊天、回合折叠、插件设置页等），以及按反馈迭代的 **新会话视图改版**（Codex 新对话
布局：输入卡居中、项目选择器在输入卡上方、建议卡在下方）。

## 新功能

- **空会话欢迎页 / 新会话视图**：空白会话为 Codex 式新对话布局——问候语 +
  项目选择器（输入卡上方居中）+ 输入卡（垂直居中于右半区）+ 建议卡（输入卡下方，
  点击填入输入框）；开始对话后回到常规贴底对话布局。
- **项目归属选择**：新会话可任意选择项目——已注册项目一键切换，或「选择文件夹…」
  打开系统对话框选任意地址（自动注册为项目并在其中新建会话）；**一旦开始对话，
  会话归属锁定，不再提供切换入口**。
- **附件上传**（＋菜单 → 上传附件）：文件复制进工作区 `.dsh/uploads/<时间戳>/`
  并在消息中注明路径，Agent 用文件工具读取（图片可被 read-image 工具消费）；
  单个 ≤ 20 MiB，每条消息 ≤ 8 个，输入框 chips 预览、可移除。
- **任务完成折叠**：回合结束后过程（思考 / 工具 / 中间回复）默认收进「任务过程」
  折叠块，只展示最终回复，可展开回看；运行中保持实时全量渲染。
- **插件设置页**（设置 → 扩展 → 插件）：内置组合行（cordis.yml）状态展示 +
  自定义插件安装（名称 + 入口 JS 文件）、启停、删除；「应用变更」重启引擎生效。

## 修复

- 会话标题冷启动批量拉取（`session:titles`）——未打开过的会话不再显示
  `session-xxxx` id 前缀或错误回退名，空白会话显示「新对话」。
- 归档语义闭环：启动不再自动打开已归档会话；归档当前会话后立即切到新会话。
- 「最近」区改为跨项目最近 8 条平铺（原先只列其他项目会话，单项目用户恒为空）。
- 侧栏会话行操作按钮改为行内流式布局——悬停时长标题收缩出省略号，不再重叠。
- ＋号移到输入框工具栏最左；工具栏允许换行（窄窗不再挤压），输入框展开上限 320px。
- 对话流与输入卡同宽居中（820px），宽窗口不再占满右半区。
- 启动性能：harness boot/llm 模块并行预载，与 Electron 初始化重叠（boot 耗时日志）。
